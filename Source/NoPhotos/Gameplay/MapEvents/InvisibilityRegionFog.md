# 투명화 이벤트 구역 표시 — 부드러운 영역 안개

## 현재 설정 안내

기존의 균일한 박스 표면 안개막은 모서리가 직각으로 드러나는 문제가 있어 **영역 안을 통과하는 깊이로 농도를 계산하는 방식**으로 변경했습니다.

**기존 단순 Opacity 연결은 교체해야 합니다.** 머티리얼 설정, Custom 노드 입력과 붙여 넣을 코드, 에디터 튜닝값은 [부드러운 영역 안개 설정](SoftRegionFog.md)에 정리했습니다. 사용자가 직접 에셋을 수정하고 C++를 빌드해야 합니다.

## 이벤트와 볼륨의 역할

- `NPMapEventSpawnVolume`의 소스/에셋/숨김/충돌/복제 설정은 변경하지 않습니다.
- `NPInvisibilityMapEvent`가 활성화된 동안에만 별도 표시 메시를 소유합니다. 다른 이벤트는 표시를 생성하지 않습니다.
- Cube는 화면에 그릴 면이 아닌 안개 계산의 프록시입니다. 내부 깊이, 가장자리 감쇠, 둥근 모서리, 흐르는 밀도로 최종 불투명도를 계산합니다.
- 실제 진입/이탈 판정은 기존 박스 그대로입니다. 흐릿한 모서리 역시 이벤트 판정 영역에 포함됩니다.
- 구역 내부에서의 개인 시야 감소는 기존 `VisionRestriction` 후처리가 계속 담당합니다.

## 설정 위치 구분

| 용도 | 머티리얼 종류 | 지정 위치 |
|---|---|---|
| 자기 캐릭터 반투명 | Surface | Pawn → Invisibility → Self Material Override |
| 개인 시야 제한 | Post Process | Pawn → VisionRestriction → Vision Fog Material |
| 외부에서도 보이는 구역 안개 | Surface, 깊이 적분 Custom 노드 | 이벤트 BP → Region Fog Material |

## 수명과 복제

서버가 실제 판정에 사용한 볼륨의 Transform/Extent를 복제합니다. 클라이언트에 SpawnVolume 또는 서버 전용 위치 레벨이 없어도 표시합니다. 볼륨 이동·회전·스케일·크기·목록 변경은 다음 서버 판정과 네트워크 복제에 따라 갱신됩니다.

표시 메시와 영역별 MID는 각 클라이언트에서 생성합니다. 초기 RepNotify/BeginPlay 순서와 이벤트 상태/영역 데이터 수신 순서를 처리합니다. Listen Server는 호스트 화면에도 표시하고 Dedicated Server는 메시를 생성하지 않습니다.

이벤트 종료, 액터 EndPlay, 볼륨 제거와 레벨 언로드 때 표시를 정리합니다. 충돌/Overlap/내비게이션 영향/그림자는 없으며 이동·잡기 판정에 쓰지 않습니다. Show Region Fog를 끄면 표시만 생략하며 플레이어 효과는 유지됩니다.

## 제한과 담당 범위

- 에디터 편집 화면에는 표시하지 않습니다. 이벤트 활성 중 실제 플레이에서 확인합니다.
- 겹친 박스는 안개가 중복 합성되어 더 짙어질 수 있습니다. 합집합 밀도 계산은 구현하지 않았습니다.
- 부드러운 경계 폭과 모서리 둥글기는 시각 표현 전용입니다. 서버 판정 영역이 둥글게 바뀌지는 않습니다.
- 사진/UI 코드는 변경하지 않았습니다. 일반 월드 표시이므로 SceneCapture 설정에 따라 사진 이미지에 나올 수 있지만 증거 판정의 자동 연동을 의미하지 않습니다.
- 기본 SpawnVolume Root인 SpawnBounds(UBoxComponent)를 읽습니다. 파생 BP에서 Root 구조를 바꾼 별도 Volume 형식은 표시 대상에 포함하지 않습니다.

빌드/셰이더 컴파일/PIE/에셋 생성 및 수정은 수행하지 않았습니다. 정적 검토와 독립적인 안개 수식 검증만 수행합니다.
