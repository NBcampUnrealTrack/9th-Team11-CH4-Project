# 산타 이벤트: 비행 경로와 선물 투하

이벤트 시간 동안 산타가 배치된 랜덤 경로를 반복 비행합니다. 첫 비행은 즉시 시작하고, 한 번 지나갈 때마다 사라진 뒤 설정한 최소~최대 시간 사이의 랜덤 대기 후 다시 등장합니다. 각 비행 방향은 정방향/역방향을 50% 확률로 선택합니다. 경로 위에서 선물상자를 투하하고 착지 후 플레이어가 잡으면 개봉해 랜덤 유물을 생성합니다. **UI, 사진 판정, 기존 SpawnVolume이나 다른 이벤트는 변경하지 않습니다.** 선물 설정은 같은 폴더의 `SantaGift.md`를 참고하세요.

## 구성

| 클래스 | 역할 |
| --- | --- |
| `NPSantaMapEvent` | 이벤트 수명 안에서 서버가 경로/방향 선택, 반복 생성/제거, 랜덤 대기 관리 |
| `NPSantaEventDefinition` | 메타데이터/전체 Duration + 1회 비행/대기 범위/산타 외형/경로 그룹 DA |
| `FNPSantaFlightSchedule` | 1회 Flight Duration과 Respawn Delay Min/Max 설정 |
| `NPSantaFlightRoute` | 레벨에 배치하는 직선 경로 기준점. 에디터에 선/방향 화살표 표시 |
| `NPSantaFlightActor` | 산타 외형과 비행. 서버에서 받은 시작점/끝점/시작 시각/Duration으로 이동 |
| `FNPSantaFlightPlan` | 복제할 비행 데이터. 진행률과 위치 계산은 이 구조체에서 공유 |
| `NPSantaGiftActor` | 독립된 선물상자. 서버 낙하/착지, 개봉 연출, 랜덤 유물 1개 생성 |
| `FNPSantaGiftDropSchedule` | 비행 중 투하 수량과 진행 구간 설정 |

## 사용자가 에디터에서 설정할 것

BP/DA/레벨 에셋은 이 변경에서 수정하지 않습니다. 새 C++ 클래스가 반영된 에디터에서 아래를 설정하세요.

### 1. 산타 외형 BP

1. 부모 클래스를 **NPSantaFlightActor**로 하는 `BP_SantaFlight`를 만듭니다.
2. 상속된 `SleighMesh`에 썰매 Static Mesh, `SantaMesh`에 산타 Skeletal Mesh/애니메이션을 지정합니다. 하나만 사용해도 됩니다. 기본 외형 에셋은 코드에서 지정하지 않습니다.
3. 위치/크기/회전은 각 메시 또는 `VisualRoot`의 상대 Transform으로 조절합니다. 모델 정면은 비행 액터의 **로컬 +X**입니다. 모델이 뒤를 보면 `VisualRoot`의 Yaw를 조절하세요.
4. 추가 외형 컴포넌트도 `VisualRoot` 아래에 붙이고 충돌/물리 시뮬레이션을 끄세요. 기본 두 메시의 충돌/오버랩/Nav 영향은 코드에서 꺼두었습니다.
5. **Replicates / Always Relevant는 켜고, Replicate Movement는 끈 상태**를 유지합니다. BP의 Tick/Timeline/MovementComponent로 별도 이동시키지 않습니다.

### 2. 직선 경로 배치

메인 레벨 또는 카탈로그의 선택적 `Location Level Instance` 원본 레벨에 **NPSantaFlightRoute** 액터를 배치합니다. 별도 경로 BP는 필수가 아닙니다.

| 항목 | 의미 / 예시 |
| --- | --- |
| 액터 Location | 비행 구간의 기준 중심. X/Y를 바꾸면 경로 전체가 이동 |
| 액터 Rotation Yaw | 경로의 기준 정방향. 실제 비행에서는 정방향/역방향을 랜덤 선택 |
| Flight Height | 기준 중심에서 월드 위쪽으로 더하는 높이. 기본 2000cm |
| Flight Distance | 시작점부터 끝점까지 전체 길이. 기본 12000cm |
| Route Group | 기본 `Santa`. 이벤트 DA와 정확히 같아야 함 |
| Selection Weight | 기본 1. 0이면 선택하지 않음 |

```text
중심 = 액터 위치 + (0, 0, FlightHeight)
방향 = 액터 Yaw가 향하는 수평 단위 벡터
시작 = 중심 - 방향 × FlightDistance / 2
끝   = 중심 + 방향 × FlightDistance / 2
```

- 에디터의 경로 선과 빨간 화살표로 배치를 확인합니다. 화살표는 기준 정방향만 표시하며 실제 비행은 반대로도 진행합니다. 게임 중에는 표시하지 않습니다.
- 미리보기 Spline 점을 직접 옮기지 말고 **액터 위치/Yaw, Height, Distance**를 수정하세요. 점은 Construction에서 다시 계산합니다.
- Pitch/Roll/Scale은 비행 경로 계산에서 무시합니다. 액터 Scale은 1로 두고 길이는 Distance로 설정하는 것을 권장합니다.
- 지면 높이 탐색이나 장애물 회피는 없습니다. 건물/산을 지나지 않게 높이를 배치하고 확인하세요.
- Collector, SpawnPoint, SpawnVolume, NavMesh는 이 이벤트 경로에 필요하지 않습니다.
- 같은 그룹의 유효한 경로가 여러 개면 직전 경로를 제외한 후보 중 가중치로 하나를 고릅니다. 유효한 경로가 하나뿐이면 재사용합니다. 매 비행마다 정방향/역방향을 50% 확률로 추첨하며 역방향에서는 시작점/끝점과 산타의 바라보는 방향이 함께 뒤집힙니다.
- 현재 로드된 모든 레벨에서 해당 그룹을 검색합니다. 경로 세트를 분리하려면 별도 Gameplay Tag를 등록하고 DA/경로에 동일하게 지정하세요.

### 3. 이벤트 DA / 카탈로그

1. **NPSantaEventDefinition** 타입의 Data Asset을 만듭니다. 일반 `NPMapEventDefinition` DA에는 산타 설정이 없습니다.
2. `Event Class` = **NPSantaMapEvent**. 필요하면 사용자가 만든 해당 클래스 자식 BP를 지정해도 됩니다. Apply Event State를 BP에서 재정의하면 부모 호출을 유지해야 합니다.
3. `Santa Class` = 위에서 만든 **BP_SantaFlight**, `Route Group` = **Santa**.
4. 기존처럼 Event Id, Display Name, Type, Scale 등 메타데이터를 설정합니다.
5. `Duration`은 **대기 시간을 포함한 전체 이벤트 시간**입니다. 예: **60초**. 0초/무제한은 지원하지 않으며 최소 0.01초입니다. `Santa Event → Flight → Flight Schedule`의 `Flight Duration`은 **1회 비행 시간**(기본 8초), `Respawn Delay Min/Max`는 **비행 종료 후 재등장까지 대기 범위**(기본 3~7초)입니다. 12000cm / 8초이면 속도는 1500cm/s입니다.
6. 기존 `DA_EventCatalog`의 `Event Entries`에 이 DA와 이벤트 선택 가중치를 넣습니다.
7. 별도 위치 레벨을 사용한다면 해당 엔트리의 `Location Level Instance`에 경로 액터가 있는 레벨을 지정합니다. 메인 레벨에 이미 경로가 있으면 비워도 됩니다.
8. 선물 투하를 쓰려면 DA의 `Gift Class`, `Relic Classes`, `Gift Drops`를 설정합니다. 상세는 `SantaGift.md`를 참고하세요. `Gift Drops.Count = 0`이면 비행만 합니다.

기존 이벤트의 `Location Source`는 Point/Volume용 설정이며, 산타의 경로 선택에는 사용하지 않습니다.

### 반복 비행 설정 예

| DA 항목 | 예시 | 의미 |
| --- | --- | --- |
| Duration | 60초 | 전체 이벤트 수명 |
| Flight Schedule → Flight Duration | 8초 | 경로를 한 번 통과하는 시간 |
| Flight Schedule → Respawn Delay Min | 3초 | 비행 종료 후 최소 대기 |
| Flight Schedule → Respawn Delay Max | 7초 | 비행 종료 후 최대 대기 |
| Gift Drops → Count | 5개 | 이벤트 전체가 아니라 **매 비행마다** 투하하는 개수 |

예: 0초 등장 → 8초 퇴장 → 랜덤 4초 대기 → 12초에 새 경로/방향으로 등장 → 20초 퇴장 → 랜덤 대기… → 60초에 모두 중단합니다. 등장 시점 간 간격은 `Flight Duration + 이번에 뽑은 대기 시간`이며 동시에 여러 산타가 비행하지 않습니다.

- Min/Max는 유한한 값이고 `0 <= Min <= Max`여야 합니다. 둘이 같으면 고정 간격, 둘 다 0이면 비행 종료 다음 틱에 재등장합니다.
- 다음 재등장 시각이 이벤트 종료 시각 이상이면 예약하지 않습니다. 마지막 비행 도중 이벤트 시간이 만료되면 즉시 정리하며 끝점에 맞추려고 속도를 높이지 않습니다. 미실행 선물 슬롯도 취소합니다.
- 기존 DA는 저장된 Duration/선물/외형을 유지하고 새 Flight Schedule의 기본값(8초, 3~7초)을 사용합니다. 반복 횟수를 늘리려면 Duration을 충분히 길게 설정하세요.
- `BP_SantaFlight.BeginPlay`의 이펙트/사운드도 **매 재등장마다** 실행됩니다. 이벤트 전체에 한 번만 필요한 효과는 `BP_SantaEvent.Apply Event State`에서 관리하세요.

## 실행 / 복제 / 정리

- 기존 매니저가 이벤트 시작 시점과 전체 수명을 관리합니다. 서버는 **매 비행 시작마다** 현재 로드된 경로와 방향을 새로 고르고 월드 시작점/끝점/현재 서버 시작 시각을 확정합니다. 비행 중 경로 액터를 옮겨도 진행 중인 비행은 바뀌지 않습니다.
- 산타는 서버의 Persistent Level에 생성됩니다. 경로 전용 위치 레벨이 서버에만 있어도 클라이언트는 복제된 계획만으로 비행합니다.
- 각 화면은 GameState의 서버 시각으로 진행률을 계산합니다. 늦게 접속해도 계획 수신 후 현재 진행률을 사용합니다. 별도 이동 복제와 이중 보간하지 않습니다.
- 1회 비행 종료 시 산타와 해당 비행의 투하 타이머만 정리하고 재등장을 예약합니다. 이벤트 자체는 종료하지 않습니다. 클라이언트도 비행 종료 시각 이후에는 외형을 숨기고 서버의 제거 복제를 기다립니다.
- DA Duration 만료, 수동 FinishEvent, 이벤트 액터 제거 시 현재 산타와 모든 비행/투하/재등장/실패 종료 타이머를 취소합니다.
- 첫 비행의 설정 오류/경로 없음/생성 실패는 `LogNPSantaEvent` 경고 후 다음 틱에 종료합니다. Started → Finished 순서를 보존합니다. 반복 비행 사이 경로가 사라지거나 생성이 실패하면 랜덤 간격 후 재시도하며 전체 수명은 유지합니다.
- 산타가 비행 도중 외부에서 Destroy되면 해당 비행을 정리하고 랜덤 대기 후 다시 생성합니다.
- 이벤트는 같은 인스턴스에서 재시작할 수 있으며, 모든 이전 타이머/산타/직전 경로 기억은 먼저 정리합니다.
- 선물은 현재 서버 비행 진행률로 계산한 산타 위치 바로 아래에서 떨어집니다. 투하 슬롯은 매 비행마다 처음부터 시작합니다. 비행 종료 시 새 투하는 멈추지만 이미 떨어진 선물은 착지 후 잡기를 기다립니다. 이벤트 종료 후에도 잡아서 개봉할 수 있고 생성된 유물도 남습니다. `GetSanta()`는 **비행 사이 대기 중에는 정상적으로 null**이며 클라이언트의 복제 도착 순서에 따라 잠시 null일 수도 있습니다.

## 검증 안내

`NPSantaFlightTests.cpp`의 `NoPhotos.MapEvents.Santa` 테스트는 경로/정·역방향/진행률/투하 계산, 랜덤 대기 범위, 격리된 테스트 월드의 반복 생성·투하·종료·재시작·단일 경로·0초 대기·외부 제거를 검증합니다. 실제 BP 외형과 네트워크 동기화는 아래 항목을 PIE에서 별도로 확인해야 합니다.

2026-08-31 검증: UE 5.7 UHT와 산타 이벤트/설정/테스트 C++ 컴파일은 통과했습니다. 실행 중인 에디터가 `UnrealEditor-NoPhotos.dll`을 점유해 링크가 LNK1104로 실패했으므로 자동화 테스트는 아직 실행하지 않았습니다. 에디터 종료 후 빌드를 마무리하고 위 테스트 필터를 실행해야 합니다.

에디터 실행 확인 항목:

1. 경로 위치 이동 / Yaw 0·90·임의 각도에서 미리보기와 산타 이동이 일치하는지.
2. Listen Server 및 Dedicated Server + 클라이언트 2개에서 진행 위치/방향이 일치하는지.
3. 비행 중 접속한 클라이언트가 시작점부터 다시 비행하지 않는지.
4. Duration 종료 / 수동 종료 / 재실행에서 이전 산타가 남거나 중복되지 않는지.
5. 그룹 불일치, 가중치 0, 산타 클래스 누락, Duration 0일 때 경고 후 종료되는지.
6. 서버 전용 Location Level Instance에 경로를 넣어도 클라이언트에서 산타가 보이는지.
7. 경로가 없는 상태에서 실패 종료 후 다음 이벤트가 정상 실행되는지.
8. Duration=60, Flight Duration=8, Respawn Delay=3~7에서 비행 종료 후 3~7초 사이에 재등장하고, 매 비행마다 선물 수량이 다시 적용되는지.
9. 두 개 이상의 경로에서 직전 경로를 연속 선택하지 않고, 양쪽 방향 모두 비행하며 역방향에서도 산타 정면/선물 투하 위치가 맞는지.
10. 대기 중 종료/비행 중 종료/대기 중 접속/비행 중 외부 Destroy에서 중복 산타나 종료 후 투하가 없는지.

이 검증은 아직 실행 결과가 아닌 사용자 확인 절차입니다.
